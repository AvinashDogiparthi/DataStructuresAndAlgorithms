# 429. N-ary Tree Level Order Traversal

🔗 Problem Link: [LeetCode - N-ary Tree Level Order Traversal](https://leetcode.com/problems/n-ary-tree-level-order-traversal/)

---

## Problem Statement

Given the `root` of an **N-ary tree**, return the **level order traversal** of its nodes' values.

In an N-ary tree, each node can have **zero or more children**.

The level order traversal visits the nodes **level by level**, from left to right.

N-ary tree input serialization is represented in its level order traversal, where each group of children is separated by a `null` value.
