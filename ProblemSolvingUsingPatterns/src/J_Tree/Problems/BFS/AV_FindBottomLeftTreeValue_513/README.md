# 513. Find Bottom Left Tree Value

🔗 Problem Link: [LeetCode - Find Bottom Left Tree Value](https://leetcode.com/problems/find-bottom-left-tree-value/)

---

## Problem Statement

You are given the `root` of a binary tree.

Your task is to return the **leftmost value in the last row** of the tree.

In other words, find the value of the **first node in the deepest level** of the binary tree.

---

### Example 1

**Input:**
```text
root = [2,1,3]
```

**Output:**
```text
1
```

**Explanation:**

```text
The last row of the tree is:

[1, 3]

The leftmost value is 1.

```
