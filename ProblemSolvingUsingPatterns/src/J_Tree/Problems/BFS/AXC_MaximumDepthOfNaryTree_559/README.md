# 559. Maximum Depth of N-ary Tree

🔗 Problem Link: [LeetCode - Maximum Depth of N-ary Tree](https://leetcode.com/problems/maximum-depth-of-n-ary-tree/)

---

## Problem Statement

Given the `root` of an **N-ary tree**, find its **maximum depth**.

The maximum depth is the number of nodes along the **longest path from the root node down to the farthest leaf node**.

An N-ary tree is a tree where each node can have **zero or more children**.

N-ary tree input serialization is represented in its level order traversal, where each group of children is separated by a `null` value.
