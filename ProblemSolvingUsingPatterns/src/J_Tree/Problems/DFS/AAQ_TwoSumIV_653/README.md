## Problem Statement

Given the `root` of a **Binary Search Tree (BST)** and an integer `k`, return `true` if there exist **two elements** in the BST whose sum is equal to `k`.

Otherwise, return `false`.

In other words, we need to find two different nodes such that:

```text
node1.val + node2.val = k
```
