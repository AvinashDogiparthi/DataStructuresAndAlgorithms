# 965. Univalued Binary Tree

🔗 Problem Link: [LeetCode - Univalued Binary Tree](https://leetcode.com/problems/univalued-binary-tree/)

---

## Problem Statement

A binary tree is called **uni-valued** if every node in the tree has the **same value**.

Given the `root` of a binary tree, return `true` if the tree is **uni-valued**, otherwise return `false`.
