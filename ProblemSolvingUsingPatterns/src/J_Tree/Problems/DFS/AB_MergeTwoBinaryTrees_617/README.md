# 617. Merge Two Binary Trees

🔗 Problem Link: [LeetCode - Merge Two Binary Trees](https://leetcode.com/problems/merge-two-binary-trees/)

---

## Problem Statement

You are given two binary trees `root1` and `root2`.

Imagine placing one tree on top of the other so that some nodes overlap while others do not.

The trees are merged according to the following rules:

- If two nodes **overlap**, their values are added together.
- If only one tree has a node at a particular position, that non-null node is used in the merged tree.
- The merging process starts from the **root nodes** of both trees.

Return the resulting **merged binary tree**.
