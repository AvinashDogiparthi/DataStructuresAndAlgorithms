# 110. Balanced Binary Tree

🔗 Problem Link: [LeetCode - Balanced Binary Tree](https://leetcode.com/problems/balanced-binary-tree/)

---

## Problem Statement

Given the `root` of a binary tree, determine if it is **height-balanced**.

A binary tree is considered **height-balanced** if, for every node in the tree, the difference between the heights of its left and right subtrees is **at most `1`**.

In other words:

```text
|height(left subtree) - height(right subtree)| <= 1
```
